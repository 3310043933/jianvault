# JianVault v1.6.0 · 简验证

[English](#english) | [简体中文](#简体中文)

## English

**Download `jianvault-1.6.0.apk` from Assets to install. GitHub's “Source code” ZIP/TAR files are for developers, not Android installation.**

This is the first independently signed public preview. Requires **Android 8.0 or later**. One universal APK is provided; there is no CPU-architecture selection to make.

### Included

- Offline TOTP authenticator with QR scanning and manual setup.
- Website credentials with groups, search, hidden passwords, multiline notes, and copy actions.
- Recovery codes with local used/unused flags for authenticator entries.
- User-key-encrypted TXT/clipboard backups, exact-match merge import, and separately confirmed full replacement.
- English and Simplified Chinese, selectable under Help → Language.

### Install and migrate

1. Download the APK. If Android asks, allow installation from the browser or file manager you used.
2. Set a device screen lock and open JianVault.
3. To migrate from the earlier private test app, **keep it installed**. Export an encrypted backup there, install this public app alongside it, and import using the same backup key. Check the imported records before removing the old app.

Public application ID: `io.github.jianvault.app`. Earlier test builds used `cn.local.simpleauth`; their data is not overwritten. Future public APK updates use the same public signing identity and can update this public app in place.

`SHA256SUMS.txt` contains the APK hash. `SIGNING_CERTIFICATE.txt` identifies the public release signer. Keep encrypted backups and their keys separately; the app cannot recover a lost backup key.

### Preview status

246 core checks and bilingual resource checks have passed, and the signed APK has been built and inspected. Full on-device UI, camera, document-picker, clipboard, system-authentication, and Keystore testing and an independent security audit are still outstanding. Android Lint was not completed in the original environment; this release was built with those checks explicitly skipped. This is not a claim of production security certification.

## 简体中文

**在附件 Assets 中下载 `jianvault-1.6.0.apk` 即可安装。GitHub 自动生成的 Source code ZIP/TAR 是源码，不是安卓安装包。**

这是首个使用独立正式签名的公开预览版，支持 **Android 8.0 及以上**。只提供一个通用 APK，无需选择 CPU 架构。

### 包含功能

- 离线动态验证码，支持扫码及手动输入密钥。
- 网站账号密码，支持分组、搜索、隐藏密码、多行备注及复制。
- 动态验证码条目的恢复码及本地已用状态。
- 用户自行输入 Key 的 TXT/剪贴板加密备份、完全一致才跳过的合并导入，以及单独确认的整库覆盖。
- 简体中文与 English，可在使用说明 → 语言中切换。

### 安装与旧版迁移

1. 下载 APK，按安卓提示允许当前浏览器或文件管理器安装应用。
2. 设置手机锁屏密码，打开简验证。
3. 从之前的内部测试版迁移时，**先保留旧版，不要卸载**。在旧版导出加密备份，安装与它并存的公开版，再用相同备份 Key 导入。核对数据无误后再决定是否移除旧版。

公开版应用 ID 为 `io.github.jianvault.app`；之前测试版为 `cn.local.simpleauth`，不会被覆盖。后续公开版使用同一正式签名，可直接更新这个公开版应用。

`SHA256SUMS.txt` 提供 APK 哈希，`SIGNING_CERTIFICATE.txt` 提供发布签名身份。请将加密备份和 Key 分开保存，丢失备份 Key 无法解密。

### 预览状态

246 项核心检查和双语资源检查已通过，签名 APK 已构建并检查。尚未完成真机界面、相机、文件选择器、剪贴板、身份验证、Keystore 全流程测试及独立安全审计。原环境未完成 Android Lint，本次明确跳过这些检查构建，不代表已获得正式安全认证。
