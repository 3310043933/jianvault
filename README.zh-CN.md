# 简验证 · JianVault

[English](README.md) | **简体中文**

离线安卓密码与动态验证码保险库，支持分组、备注、恢复码和加密备份。

## 功能

- **动态验证码**：扫码或手动输入 TOTP 密钥，支持 SHA1/SHA256/SHA512、6/8 位以及 1～300 秒周期。
- **网站账号密码**：保存名称、地址、账号、密码及多行备注，可分组或不分组，按名称、地址、账号搜索，复制单个字段或完整条目。
- **恢复码**：在动态验证码条目中保存并标记已使用。复制不会自动标记，也不会改变网站上的有效性；网站密码详情使用备注，不显示恢复码入口。
- **加密备份**：由用户输入 Key，导出全部保险库数据为加密文本，复制或保存 UTF-8 TXT；支持选择 TXT 或粘贴文本导入。
- **精确合并**：只有保存值全部相同才跳过，任一字段不同都另存一条；保留本机原记录，包括原有重复记录。整库覆盖是单独确认的操作。
- **中英文切换**：在**使用说明 → 语言**选择跟随系统、简体中文或 English。切换不翻译或修改已保存的名称、账号、密码、备注、分组及备份内容。

侧栏固定只有**动态验证码、网站账号密码、导入导出加密数据、使用说明**四项。分组选择及管理操作位于网站账号密码主页面。

## 使用

1. 在 Android 8.0 及以上手机安装自行构建的 APK，先设置系统锁屏密码。
2. 动态验证码用于绑定网站提供的验证器密钥或二维码；将生成的验证码填回网站完成绑定。设置密钥与登录密码是两种信息，按时间变化的是验证码数字，密钥本身不变。
3. 固定密码在网站账号密码页面新增。使用页面内的分组选择器及「管理分组」整理；删除组只将条目移到未分组，不删除数据。
4. 点击条目进入详情，可查看、编辑、移动、复制，密码默认隐藏。一键复制全部包含名称、地址、账号、密码和非空备注。
5. 在使用说明页面选择语言。切换会重新创建界面，可能需要再次通过系统身份验证。

## 备份与导入

进入**导入导出加密数据**：

- **导出**：输入并确认用户自己的 12～1024 字符 Key。大小写、Unicode 和空格原样保留。备份包含动态验证码、网站账号密码、备注、分组（含空组）、恢复码及使用状态；软件不将 Key 放入备份或持久化保存。
- **导入**：选择加密 TXT 或粘贴加密文本，输入相同 Key。解密及确认前不修改本机数据。
- **合并**：先预览新增和跳过数量。比较条目类型、名称、地址、账号、密码、备注、所属组、验证码密钥和参数、恢复码内容及顺序和已用状态。同名组先对应，内部组编号不同不算用户内容不同；分组冲突分别保留。重复导入同一备份不会继续增加条目。
- **覆盖**：另行确认后替换整个保险库，备份中没有的本机记录会删除。本机数据无法读取时不能去重，仅可选择覆盖恢复。

请将备份和 Key 分开保管，**丢失 Key 无法解密备份**。导入后使用目标手机自己的本地密钥重新加密，因此可在不同设备之间手动迁移；此功能不是自动云同步。

备份以 `SIMPLEAUTH-BACKUP-1:` 开头，使用 PBKDF2-HMAC-SHA256（600000 次迭代、16 字节随机 salt）派生密钥，再用 AES-256-GCM、12 字节随机 nonce 和认证头加密。序列化明文上限 8 MiB，加密 TXT 上限 12 MiB；剪贴板导出上限为 250000 字符，较大备份请保存 TXT。导入支持 UTF-8 BOM、CRLF 换行和 Base64 折行。

## 安全措施与当前限制

- 不申请网络权限，无遥测、广告或自动云同步。
- 本地保险库使用 AES-256-GCM 加密，AES 密钥由 Android Keystore 生成和管理。密文快照原子写入应用私有的 no-backup 目录。
- 账号数据、分组、备注和恢复码均加密保存。非敏感的界面语言偏好单独保存在本机，不包含在保险库备份中。
- 应用入口通过系统身份验证；**当前 Keystore 密钥没有设置为每次使用都必须验证身份**。界面入口验证和密钥使用授权是两层不同的保护。
- 敏感界面请求禁止截图，凭据输入框关闭 View 状态保存和自动填充，并请求输入法不进行个性化学习；这些设置不能保证第三方输入法或已被攻陷系统的行为。
- 查看数据时内存中需要明文，复制时系统剪贴板会出现明文。系统允许时，应用尝试在 30 秒后清除未变化的凭据剪贴板；后台访问可能受限制。加密备份文本不使用这个 30 秒清除计时器。
- 卸载、清除数据、手机丢失或系统密钥丢失后，本机数据可能无法读取；恢复依赖事先保存的加密备份和对应 Key。
- 本项目仍是自用测试项目。已检查 JVM 测试与 APK 构建，尚未完成真机界面、文件选择器、剪贴板、身份验证及 Keystore 端到端测试，也未进行独立安全审计。原环境因检查依赖下载问题未完成 Android Lint。

语言切换只改变界面和复制时的字段标签，不翻译用户内容或已有的稳定冲突标记，因此不会因界面语言不同而改变备份与合并行为。

## 构建

需要 **JDK 17**、**Android SDK 36** 和随项目提供的 **Gradle 8.13 wrapper**，最低 Android API 为 **26**。在 Android Studio 配置 SDK，或创建已忽略的 `local.properties`：

```properties
sdk.dir=C:/Android/Sdk
```

```powershell
.\gradlew.bat :app:assembleDebug
.\gradlew.bat :app:lintDebug
```

macOS/Linux 改用 `./gradlew`。调试 APK 位于 `app/build/outputs/apk/debug/app-debug.apk`。

公开版使用独立应用 ID `io.github.jianvault.app`，必须提供固定正式签名；旧测试版 `cn.local.simpleauth` 保留，可通过加密备份安全迁移。开发调试包使用独立的 `.debug` 应用 ID。**不要在导出并核对备份之前卸载已有保险库。** 正式构建和 GitHub 发布步骤见[发布指南](release/README.zh-CN.md)。签名私钥、密码、APK、编译产物、缓存和 `local.properties` 不进 Git。
